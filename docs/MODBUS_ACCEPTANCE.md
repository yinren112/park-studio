# Modbus 验收合同

2026-09-22，编写于采集程序实现前。主路径是实际 TCP 设备模拟进程 → 独立采集进程 → HTTP 服务 → SQLite → SSE → 浏览器。接口故障注入仅用于难以靠正常读数重现的乱序/鉴权/重试场景，不代替主链路。

| 可能失败的方式 | 端到端断言与证据 |
|---|---|
| 40001 地址偏移、湿温顺序、负数/倍率错误 | 实际 Modbus 响应及页面值，包含 -10.1°C / 65.8%RH 厂商例子 |
| 错站号、无效寄存器、越界/无效原始值 | 采集失败不生成新样本；页面时间不刷新；恢复有效配置后可继续 |
| 读取失败仍写 0 或旧读数 | 暂停设备后数据库不增长，≤20 秒离线，恢复后下一有效读数在线 |
| 告警确认错误关闭、连续越限重复告警 | UI 确认后仍越限，同一活动 ID；恢复再越限产生新 ID |
| HTTP 收到但回执丢失 | 测试转发器丢弃一次真实响应；相同样本重试返回 duplicate，数据库只有一条 |
| 采集程序重启序号归零或并行重复采集 | 持久序号递增，待确认 payload 原样恢复；同状态文件第二进程被拒绝 |
| 同序号不同主值、乱序、迟到、未来采样 | 冲突被拒绝；迟到仅入历史，不能刷新在线态；未来采样被拒绝 |
| 鉴权错误/无效批次部分应用 | 401/422/409 明确失败；无效批次前后记录数不变；采集器永久错误非零退出 |
| 把旧 PM2.5 数据解释成温度 | 旧目录主指标与当前目录不同则拒绝启动，原有数据库不自动迁移 |
| CSV/曲线跨缺测造连续 | 真实历史窗口至少一完整空桶；实际导出 CSV 空值、SVG 独立段一致 |
| server 重启、SSE 断线 | 页面保留快照，重启重新登录后新 bootId 可接；历史与告警仍在 |
| gateway 意外开放实物控制 | UI 隐藏控制，直接请求拒绝；另跑模拟模式确认原幂等语义 |
| 前端无法运行、来源误导、窄屏溢出 | 实际 WebGL 页面和截图，模拟/RTU来源明确；390×844检查 |
| 包依赖开发环境/外网 | 干净虚拟环境从离线 wheels 安装，解压包按文档启动，外部请求被拦时页面仍可操作 |

每次验收必须输出非零失败码或 PASS 报告，并保存日志、截图、CSV、视频、环境、源文件哈希和进程清理结果。实际 RTU、接线、连续 24 小时实物台架运行独立列为待验证，不由 TCP PASS 推导。
