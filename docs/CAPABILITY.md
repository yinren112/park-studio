# 园区与机房三维监测开发

ParkStudio-3D 把资产位置、读数、趋势和告警放在同一资产编号下，适合用于园区、楼宇及机房三维监测界面的技术验证和定制开发。

![园区总览](assets/workbench.png)

**可以交付**：单场景资产模型与编号映射、三维定位/剖切/设备查看、状态与告警展示、主指标历史与 CSV、本机或内网运行包、点表和验收记录。

**当前样板**：40 个虚拟资产；ENV-01 用作温湿度台架点位，温度留存历史、湿度实时显示。Modbus TCP 模拟器通过独立采集程序进入工作台。告警确认只表示知悉，读数恢复后才关闭；缺测区间保留空值。RTU 采集配置已提供，实物接线和现场运行待验收。

**两种运行方式**：静态预览（`index.html` + 样式与两个脚本文件）用于离线模拟展示；实时监测包需要 Python、本地服务、数据库和相应采集依赖。两者均无需外部 CDN。断开互联网时设备通信链路需保留。

**试点需要客户提供**：资产/场景资料、点表及寄存器手册、现有网关/API说明、可测试的数据源、目标电脑与网络条件、验收人和现场配合安排。

**试点范围**：先约定一个场景和一个数据源，按书面点表验收读数、告警、历史、断线恢复和交付包。PLC 程序改造、实物控制、完整 BMS/MES、多厂商协议及驻场服务另行评估。

这是自建虚拟园区和协议样板，不作为已交付客户案例。具体完成状态和验证环境见 [QA](QA_AND_BENCHMARKS.md) 与 [Modbus 说明](MODBUS_PILOT.md)。
